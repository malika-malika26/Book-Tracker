## Описание программы 
*Простое приложение для учёта прочитанных книг с фильтрацией и сохранением в JSON* --- 
## Требования для запуска 
- Python 3.8+
- Tkinter (обычно входит в стандартную поставку Python)
 --- 
## Как запустить 
```bash 
git clone https://github.com/твой-логин/weather-diary.git 
cd weather-diary 
python main.py 
Как пользоваться 
- Заполните поля Title, Author, Genre, Pages и нажмите "Add Book".
- Фильтрация: выберите жанр или укажите "Min Pages" и нажмите "Apply Filters". "Clear Filters" сбросит фильтры.
- "Save" сохраняет в файл по умолчанию; "Load" загружает; "Export JSON As..." — сохранить копию в выбранный путь.
- "Delete Selected" — удалить выбранные записи в таблице.
5. Данные автоматически сохраняются в data.json.
